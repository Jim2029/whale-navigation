鲸波导航 V1.4.3
📖 使用教程
建议：把鲸波导航设为浏览器首页。这样每次打开浏览器就直接进入导航台，不必再点工具栏图标 —— 设置方法见「一、开始使用」第 3 节。

1.1 安装扩展

三种浏览器(chrome/edge/Firefox等)都可以通过各自的官方扩展商店安装，均为免费。

1.2 建议：把扩展设为浏览器首页

★ 使用建议
安装后把鲸波导航设为浏览器首页，打开浏览器即进入导航台，省去一次点击；新标签页可以在当前页打开，导航页不占用标签；常用网站固定在导航台上，形成自己的「浏览器启动页」。

1.3 设置为浏览器首页

Chrome：

  1. 地址栏输入 chrome://settings/ 回车
  2. 左侧点击「启动时」
  3. 选择「打开特定页面」
  4. 点「添加新页面」，粘贴扩展地址（见下）后点「添加」
扩展地址怎么取？
先点击一次浏览器工具栏的鲸波图标，在打开的导航页地址栏里复制完整地址（形如 chrome-extension://…/pages/popup.html），再粘贴到上面的输入框。

Edge：地址栏输入 edge://settings/ → 左侧「外观」→「主页」→ 选「自定义」后粘贴同一地址。

Firefox：菜单 →「设置」→「主页」→ 在「主页和新建标签页」选「自定义网址」后粘贴。

设置完成后关闭浏览器再打开，若直接显示导航页即成功。

共 17 个分类，点击即跳转到对应区域。分类依次为：🔍 搜索引擎、⭐ 个人网址、🌐 常用网站、🎓 教育平台、🗣️ 外语学习、🧭 导航网站、🎬 多媒体类、🛠️ 工具网站、💼 职业技能、🔬 学术科研、📚 电子书籍、📜 文史经地、⚗️ 理工农医、🎮 休闲娱乐、📺 网课资源、🤖 AI资源、🎒 K12资源。

2.3 右侧内容区

网址以卡片形式排列，点击卡片即在新标签页打开（导航页保留不被覆盖）。

3.1 浏览与搜索

  • 点击左侧分类快速定位
  • 本站检索：在搜索框输入关键词，只在已收录的网址中查找，按回车执行
  • 必应 / Google：点搜索框上方的引擎标签切换，直接跳转搜索引擎

3.2 添加自己的网址

方式一：右下角「＋」按钮

  1. 点击页面右下角的圆形「＋」
  2. 填写标题、网址、描述（可选）
  3. 「所属分类」默认已是「⭐ 个人网址」，可下拉修改
  4. 点「✓ 保存」

方式二：右键收藏（推荐） —— 在任意网页右键 →「收藏到鲸波导航」→ 自动跳转到导航页并弹出已预填标题、网址的保存窗口 → 选择分类后保存。

方式三：快捷键收藏 —— 停留在目标网页，按 Ctrl+Shift+K，同样会弹出预填好的保存窗口。

快捷键冲突？
可在扩展管理页点击「快捷键」自行修改。Ctrl+Shift+K 是本扩展的默认键。

3.3 「收藏域名」与「收藏页面」切换

从右键菜单或快捷键收藏时，URL 输入框右侧有切换按钮。默认「收藏域名」：

点击后网址变为网站根地址，标题同时变为网站名称，按钮文字变为「收藏页面」：

按钮状态URL标题适用场景
收藏域名网站根地址，如 https://example.com/网站名称收藏网站本身，作为入口
收藏页面当前页面完整地址当前页面标题收藏具体文章 / 页面

网站名称优先读取页面声明的 og:site_name；识别不到时从页面标题按「标题 - 网站名」格式提取；最后回退为域名。

3.4 注册与个人网址

未登录也能使用全部预置导航。注册登录后可获得专属「⭐ 个人网址」栏目。

  1. 点击右上角头像区域
  2. 切换到「注册」标签
  3. 用户名 3-20 个字符（支持中文、字母、数字、下划线），密码至少 6 位
  4. 注册成功后自动登录

登录后把顶部视图切到「我的」，就只显示你自己收藏的网址：

数据隔离
「个人网址」只有你自己可见，不同账号严格隔离；收藏到其他分类的网址则全局共享。

本地文件：只有「个人网址」分类允许保存 file:// 地址或本地文件路径。首次使用前，请在 chrome://extensions 中打开「鲸波导航」的详情并启用「允许访问文件网址」；公共分类仍只允许 http/https。

3.5 拖拽排序

按住网址卡片拖到同分类的其他卡片上可调整顺序；拖到另一个分类栏目或左侧分类名称上，可将网址移动到该分类，包括个人网址与公共分类之间的互相移动。拖动时页面底部会出现「删除网址」区域，拖到那里并确认即可删除该网址。

3.6 个性化设置

  • 主题配色：工具栏「Theme」，6 套主题一键切换
  • 界面语言：工具栏「Language」，7 种语言即时切换
  • 个人头像：本后台「头像设置」，48 款任选

本后台共 8 个面板，默认打开「数据概览」：

  • 数据概览：统计分类与网址数量，展示全部网址列表
  • 分类管理：添加 / 删除 / 重命名分类，支持自定义 Emoji 图标
  • 网址管理：添加 / 编辑 / 删除 / 隐藏网址，支持按分类和关键词筛选
  • 批量导入：粘贴多行数据一次性导入，先预览再确认
  • 批量导出：按分类导出为 .txt，格式与导入一致
  • 头像设置：48 款头像任选
  • 使用教程：就是你正在看的这一页
  • 关于：版本信息、许可协议与联系方式

4.3 批量导入格式

每行一条，推荐格式为「分类,标题,网址」；分类留空时使用上方选择的目标分类。

格式
分类,标题,网址
示例：
常用网站,百度,https://www.baidu.com
搜索引擎,Google,https://www.google.com
也支持两列：标题,网址（使用上方目标分类）

4.4 批量导出与迁移

选择分类后点「导出为 .txt」。导出格式为「分类,标题,网址」每行一条；标题中的逗号和引号会自动转义，可直接用于另一台电脑的批量导入。

4.5 头像设置

5.1 收藏网址：一条捷径搞定

不必先打开导航页再手动填网址 —— 在任意网页右键或按 Ctrl+Shift+K，标题与网址自动预填，选个分类保存即可。三种入口：右键菜单、快捷键、页面内添加。

5.2 网站名称智能识别

切换到「收藏域名」时，标题自动变为网站标准名称，而非冰冷的域名。识别顺序：og:site_name → 页面标题「标题 - 网站名」提取 → 域名回退。

5.3 分类体系统一

书签与导航共用同一套分类体系，收藏即入库，避免「书签在一处、导航在另一处」的割裂。

5.4 登录衔接体验

未登录时点右键收藏，会先提示「收藏网址功能需要注册/登录」；确认后进入注册，注册成功自动衔接并弹出待收藏的网址窗口。

5.5 多语言与多主题

7 种语言（简体中文 / English / 日本語 / 한국어 / Español / العربية / Bahasa Indonesia）与 6 套配色，界面文字、分类名称同步切换。

5.6 批量导入导出

支持 TXT 批量导入（自动归档、自动跳过重复）与按分类导出，换电脑一键迁移。

5.7 纯本地运行，隐私无忧

  • 完全本地运行，无远程组件、统计代码或跟踪器
  • 所有数据仅保存在你自己的浏览器中
  • 不收集、不上传、不出售任何个人信息
  • 无需注册即可使用全部导航功能，注册仅为启用「个人网址」

Q1：点图标为什么打开新标签页，而不是小弹窗？

这是设计如此：整页空间更大、功能更完整。若希望打开浏览器即见导航台，请按 1.3 节设为首页。

Q2：右键收藏后为什么先跳到导航页？

收藏需要选分类并保存，因此会跳转到导航页并弹出预填好的窗口，选分类保存即可。

Q3：提示「收藏网址功能需要注册/登录」怎么办？

点「确定」进入注册，成功后会自动接续弹出收藏窗口；点「取消」则停留导航页，收藏不保存。

Q4：我的个人网址别人能看到吗？

不能。「个人网址」按账号严格隔离，其他账号完全不可见。

Q5：收藏的网址会与预置网址重复吗？

同一分类内按「网址 + 标题」联合比对，自动跳过重复项。

Q6：如何迁移到另一台电脑？

在「批量导出」按分类导出 .txt，在新电脑的「批量导入」中粘贴导入即可。

Q7：快捷键没反应？

检查是否被系统或其他软件占用（扩展管理页「快捷键」可改），以及浏览器是否允许扩展快捷键。

Q8：如何卸载？

在扩展管理页找到「鲸波导航」→「移除」。卸载会清除本地保存的全部数据，请提前导出备份。
